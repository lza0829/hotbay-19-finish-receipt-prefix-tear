# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 完成落账口径（全局唯一，禁止混用）

本系统采用 **同笔双落·原子事务**（架构一），不实现「先温层后目录 + 短窗补齐」：

- 目录归属前缀只有一个事实源：`prefix_for(tier, part_key)`（温层根 `hot/`、`warm/`、`cold/` + 分区键），登记、落账、互证、总览全部听它。
- 完成落账在单个 `BEGIN IMMEDIATE` 事务内同笔切换：`partitions.tier`、`partitions.object_prefix`、`clips.object_key`、`inventory_objects.object_key`、`migrate_jobs.status`。任一侧失败（含人为打断、目录侧缺键）整笔回滚到完成前快照，不存在半截漂移，也不存在滞后/补齐状态。
- 并发双完成同一单：写锁 + 事务内重读终态，恰好一成一拒，绝不一成一半。
- 互证在对象级漂移之外另做落账完整性检查（前缀与温层同源、段键挂在分区前缀下）；同笔双落成功不新增漂移，半截漂移必被抓，不给绿。
- 总览温层卡只统计温层与前缀已对齐的分区；未对齐单列曝光，不当成已对齐。
- 一次落账后迁移页、分区页前缀列、互证漂移条、总览经事件总线同刷，禁止只刷完成按钮。

测试：`cd backend && python -m pytest tests/`（12 项，含并发双完成与整笔回滚）。
